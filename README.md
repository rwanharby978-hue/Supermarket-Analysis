# Supermarket Sales Analysis
## 📌 Project Description
This project focuses on cleaning, processing, and analyzing supermarket sales data using **Python (Pandas)** and visualizing actionable business insights through an interactive **Power BI** dashboard.
**The dataset used in this project is:** `SuperMarket.csv`

The goal is to clean and transform raw supermarket transaction data and develop an interactive Power BI dashboard that answers key business questions through clear, data-driven insights.
## 🛠️ Tools Used
- Python
- Pandas
- Power BI

## 🧹 Data Cleaning
The following data-cleaning steps were performed:
- Checked data types
- Checked missing values
- Checked duplicate records
- Renamed columns
- Removed unnecessary columns
- Corrected data types
- Sorted the data
- Create 3 columns (Day, Month, Year )
- Created the `satisfied` column based on the rating
Satisfaction Rule:
`Rating >= 7 → Satisfied Else  → Not Satisfied`
